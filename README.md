# AIT-OTP-Simulator

A safe, simulated environment for studying Artificially Inflated
Traffic (AIT) against SMS-based One-Time Password (OTP) systems.

## Research Question

How do different defensive techniques perform as artificially
inflated OTP traffic becomes increasingly distributed and
difficult to distinguish from legitimate user activity?

## Objectives

- Simulate legitimate OTP traffic
- Simulate multiple AIT attack patterns
- Evaluate rate limiting
- Evaluate rule/risk-based detection
- Evaluate machine-learning anomaly detection
- Measure detection and false-positive rates
- Measure detection latency
- Estimate SMS costs prevented
- Analyze defender costs
- Analyze attacker economics

## Safety

This project uses a simulated OTP/SMS environment and does not
send real SMS messages or interact with real telecommunications
services.
